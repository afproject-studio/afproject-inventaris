# AF Project Inventaris

Sistem inventaris berbasis web dengan modul **Admin**, **Server**, dan **User** untuk membantu pengelolaan data barang, peminjaman, dan riwayat peminjaman.

---

## Fitur Utama

### Admin
- Login admin
- Dashboard admin
- Kelola data barang
- Tambah, edit, dan hapus barang
- Kelola data peminjaman
- Melihat riwayat peminjaman

### User
- Login user
- Dashboard user
- Melihat data barang
- Melakukan peminjaman barang
- Melihat riwayat peminjaman
- Reset / ubah password

### Server
- Backend Node.js
- Koneksi Firebase
- Menyimpan dan mengelola data inventaris
